3. API (provided; do not declare it)
   object Move { UP = 0; DOWN = 1; LEFT = 2; RIGHT = 3; DX = 0,0,-1,1; DY = -1,1,0,0 }   // y grows downwards
   class Enemy { id; score; direction; body: IntArray /* head first */ }
   class Perception {
       width; height; turn: Long; myId; myScore; myDirection
       myBody: IntArray                   // head first; cell = y * width + x
       foods: IntArray; enemies: Array<Enemy>
       bodies: ByteArray                  // body cells of all snakes (you included)
       selfCollision; selfCollisionWarning; wallCollision; enemyCollision; toroidal   // what kills you now
       validMoves: IntArray               // moves that do not reverse into your neck
       turnsWithoutFood; starvationTurns
       previousReward: Float              // +15 ate, -15 died, +1 closer to food, -1.2 farther
       diedLastStep; stateVector16: FloatArray
       fun nanosLeft(): Long              // time left in this call
       fun foodRivalDistance(i): Int      // foods[i]: moves from the nearest rival head (Int.MAX_VALUE if none)
       marks: IntArray; queue: IntArray   // scratch for searches (queue = width*height+1)
       fun newMark(): Int                 // a value no cell of marks holds yet
   }
 - Perception is valid only inside decide(); read-only except marks and queue; never keep its arrays.

4. LIMITS
 - Time: 100 ms / number of snakes per call (0.1-15 ms; 20 snakes = 5 ms). Over twice that, an exception or an
   invalid move = a random move. The phone is slower than the PC: check p.nanosLeft().
 - Memory: under 256 KB per Tactic. No board-sized arrays: use p.marks and p.queue.
 - Code size: rank = best score x (1 - 0.05 x log2(your chars / the shortest file's chars)).
 - Forbidden (disqualified): java./javax./android./kotlinx./dalvik., System, Runtime, Thread, ThreadLocal, Process,
   Class, ClassLoader, reflection, Unsafe, print/readLine, files, network, clocks (time only via nanosLeft()),
   external, @JvmStatic, @Volatile, synchronized.

5. GAME
 - Board: p.width x p.height cells (phone 195x90 or 390x180, PC 195x110). Never assume a size.
 - Food: +1 score, +1 length. Foods = 0.8 x snakes (min 8). Dying sends you back to length 1, score 0, and leaves
   food on every 2nd cell of your body.
 - What kills, by your score: below 100 nothing (the board wraps). From 100 (after a 600-turn warning) your own body.
   From 200 the walls (no wrap). From 300 rivals' bodies; a head-on kills everyone there with 300+. The move that
   reaches 300 already counts as 300.
 - Each turn: all choose, all move, all eat (two heads on one food: the first in the list eats), then deaths.
 - A tail cell that is leaving is safe, except the turn after that snake ate.
 - Starvation: 1500 turns without food = death.
 - Rivals: other tactics, learning DQN snakes and, on the phone, humans.

6. WHAT WINS (from the telemetry)
 - Almost every death is your own body at 200+. After each candidate move, flood-fill the free space; your body cell
   k (head = 0) is free from step length-k (+1 per meal not yet digested).
 - Floods overwrite p.marks: restore your body's marks before each candidate's flood.
 - Demand about 2 x your length of free space before entering an area.
 - Hungry is not desperate: keep demanding room until ~150 turns before starvation.
 - From 300: block rivals' bodies and the cells next to rival heads; skip food a rival reaches first.
 - Stop between candidates when nanosLeft() <= 0, keeping the best so far.
